# WebDL - 网页全量资源抓取工具

> 基于 Python、Tkinter 与 Playwright 开发的现代化桌面客户端，支持浏览器内核驱动、动态资源嗅探、多语言/无痕模式配置以及高效的异步并发下载。

---

## 核心功能特性

* **多浏览器内核支持**：完美支持调用本地的 Google Chrome 或 Microsoft Edge，并在环境缺失时自动回退至 Playwright Chromium。
* **智能资源嗅探**：实时监听网页运行中的网络响应（Response），自动过滤并抓取页面中的图片、脚本、媒体及各类静态资源。
* **多语言与无痕定制**：支持自由切换 `zh-CN`、`en-US`、`ja-JP`、`ko-KR` 等 7 种主流语言和时区，内置无痕/缓存隔离模式。
* **高效异步并发下载**：引入独立多线程下载队列，支持断点、同名文件校验跳过与自动创建层级目录。
